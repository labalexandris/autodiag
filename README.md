# AutoDiag

Web εφαρμογή για το ηλεκτρολογείο αυτοκινήτων **Παπουτσάκης & Κώτσας ΟΕ** ([autodiag.gr](https://autodiag.gr)):
online ραντεβού, ψηφιακό βιβλιάριο ανά όχημα, SMS υπενθυμίσεις, αναφορές και σύνδεση με το ημερολόγιο του κινητού.

> Κατάσταση: **MVP με mock δεδομένα**. Η βάση (Neon), τα SMS και το Google Calendar είναι προσομοιωμένα.

## Τοπικά

```bash
npm install
npm run dev        # http://localhost:3000
```

Σε εταιρικό δίκτυο με TLS inspection, αν το `npm install` κολλάει: `NODE_OPTIONS=--use-system-ca npm install`.

| `/admin/calendar` | Συνεργείο | Εβδομάδα, νέο ραντεβού από τηλέφωνο ή με κλικ σε κενή ώρα |
| `/admin/customers` | Συνεργείο | Πελάτες, αναζήτηση με όνομα, πινακίδα ή τηλέφωνο |
| `/admin/vehicles/[plate]` | Συνεργείο | Ψηφιακό βιβλιάριο και νέα εργασία |
| `/admin/reports` | Ιδιοκτήτες | Έσοδα, υπηρεσίες, no-shows, πηγές κρατήσεων, SMS |
| `/admin/settings` | Συνεργείο | Λογαριασμός, χρήστες (ιδιοκτήτες), Google Calendar, πρότυπα SMS, υπηρεσίες, ωράριο |

## Δομή

```
src/lib/types.ts        τύποι (αντιστοιχούν 1:1 με τους μελλοντικούς πίνακες)
src/lib/mock/seed.ts    mock δεδομένα, σχετικά με τη σημερινή ημέρα
src/lib/data.ts         ΤΟ data layer: async συναρτήσεις, μόνο αυτό αλλάζει για Neon
src/lib/views.ts        συνδυασμοί για τις σελίδες
src/lib/hours.ts        το ωράριο (shop.hours) για άξονες, ημερολόγιο και κείμενα
src/lib/users.ts        χρήστες και ρόλοι στο Neon (owner / staff)
src/lib/auth.ts         υπογεγραμμένο cookie σύνδεσης, μαζί με το src/proxy.ts
src/lib/auth-server.ts  requireUser / requireOwner για σελίδες και ενέργειες
src/components/         πινακίδα, καταστάσεις, βιβλιάριο, admin
```

## Design

- **Η πινακίδα είναι το κλειδί**: παντού το όχημα εμφανίζεται ως ελληνική πινακίδα. Η αναζήτηση δέχεται λατινικά (`ikb4821` → `ΙΚΒ-4821`). Συντόμευση `/`.
- **Καταστάσεις με το χρώμα ασφαλειών**: κίτρινη (αναμονή), μπλε (επιβεβαιωμένο), πορτοκαλί (σε εξέλιξη), πράσινη (ολοκληρώθηκε), κόκκινη (δεν ήρθε).
- Χρώματα: μπλε του brand `#1E5FB8`, γραφίτης `#1E2226`, κίτρινο πολύμετρου μόνο για «τώρα / προσοχή».
- Γραμματοσειρές: Fira Sans + Fira Sans Condensed (με ελληνικά).
- Το admin σχεδιάστηκε πρώτα για κινητό (bottom nav, sheets), γιατί θα χρησιμοποιείται μέσα στο συνεργείο.

## Κανόνες κράτησης

- Η ελεύθερη θέση ελέγχεται ξανά τη στιγμή της υποβολής. Αν η ώρα κλείστηκε στο μεταξύ, ο πελάτης γυρίζει στην επιλογή ώρας.
- Το ραντεβού ανήκει σε όποιον το έκλεισε (ταύτιση με το κινητό). Αν δεν είναι ο ιδιοκτήτης που έχουμε για την πινακίδα, το συνεργείο βλέπει προειδοποίηση και αποφασίζει αν αλλάζει ο ιδιοκτήτης.
- Ημέρες και ώρες βγαίνουν παντού από το `shop.hours`.

## Deploy (Render)

`render.yaml` στο root. **Απαραίτητο `TZ=Europe/Athens`**, αλλιώς οι ώρες μετατοπίζονται.
Όρισε `DATABASE_URL` (Neon). Το `SESSION_SECRET` το φτιάχνει το Render.

## Χρήστες

- **Ιδιοκτήτης**: τα πάντα, μαζί με αναφορές και διαχείριση χρηστών (Ρυθμίσεις → Χρήστες).
- **Υπάλληλος**: χωρίς αναφορές, χωρίς απόρριψη/ακύρωση ραντεβού.
- Ο πίνακας `users` φτιάχνεται μόνος του. Αν είναι άδειος, μπαίνουν οι `manolis` και `dimitris` (κωδικός `123`).
- Χρήστες δεν διαγράφονται, απενεργοποιούνται. Πάντα μένει τουλάχιστον ένας ενεργός ιδιοκτήτης.
